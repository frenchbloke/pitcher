# Turntable Pitch Deck

Precision 33 and 45 RPM vinyl speed and ±8% pitch control with interactive waveform playback and WAV export.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Standalone

`standalone.html` is a self-contained single-file version that can be opened directly in a modern browser.
